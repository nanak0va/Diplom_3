# Задание 3. Автотесты для UI
В последнем задании тебе нужно протестировать веб-приложение Stellar Burgers.
## Что нужно сделать
Опиши элементы, которые будешь использовать в тестах, с помощью Page Object.
Протестируй функциональность в Google Chrome и Яндекс Браузере. Подключи Allure-отчёт.
### Регистрация
Проверь:
- Успешную регистрацию.
- Ошибку для некорректного пароля. Минимальный пароль — шесть символов.
### Вход
Проверь:
- вход по кнопке «Войти в аккаунт» на главной;
- вход через кнопку «Личный кабинет»;
- вход через кнопку в форме регистрации;
- вход через кнопку в форме восстановления пароля.
### Раздел «Конструктор»
Проверь, что работают переходы к разделам:
- «Булки»;
- «Соусы»;
- «Начинки».

# Запуск тестов
Для запуска тестов в Google Chrome и Яндекс Браузере необходимо:
- В файле [application.yaml](src/main/resources/application.yaml) указать путь до драйвера и бинарников:
````yaml
browser:
  #название браузра, в котором будет выполняться тесты
  #может быть переопределено параметром mvn test -DrunIn=
  runIn: chrome

  chrome:
    # если не указан, то будет использован автоматически найденный браузер и драйвер к нему
    binary-path:

  yandex:
    #путь к исполняемому файлу браузера, обязательно для yandex
    binary-path:
    #путь к исполняемому файлу драйвера, обязательно для yandex
    #Скачайте драйвер для Yandex Browser с официального сайта: https://github.com/yandex/YandexDriver/releases
    driver-path:
````

Тесты запускаются командой
```
mvn clean test
```
параметр -DrunIn может принимать значения chrome или yandex, по умолчанию - chrome
```
mvn clean test -DrunIn=yandex
```
